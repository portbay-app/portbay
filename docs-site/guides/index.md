# Guides

These guides cover day-to-day operations once PortBay is installed.

| Guide | Use it when |
| --- | --- |
| [Overview Dashboard](/guides/overview) | You want one place that answers "what have my agents been doing?" across every project. |
| [Workflows](/guides/workflows) | You want to automate something — agents, browsers, databases, connectors — as a graph you can run, schedule, or trigger from a webhook. |
| [Multi-Device Sync](/guides/sync) | You use PortBay on more than one Mac and want the same projects, boards and workflows on both. |
| [Screen Capture](/guides/capture) | You want area/window/scrolling/GIF captures, a searchable capture library, and captures that feed cards and workflows. |
| [Session Recordings](/guides/recordings) | You want a sanitized, replayable record of what was run on a remote host. |
| [Networking & DNS](/guides/networking) | A hostname won't resolve, dnsmasq or the hosts helper needs explaining, or you're diagnosing DNS under a VPN. |
| [Certificates](/guides/certificates) | The local CA, per-project HTTPS, or a custom certificate needs explaining or troubleshooting. |
| [Domains](/guides/domains) | You want per-project routing knobs — path prefix, resolver mode, wildcard subdomains, expose-when-running. |
| [Caddy and HTTPS](/guides/caddy-https) | A hostname does not route, certificates fail, or Caddy is out of sync. |
| [PHP Setup](/guides/php-setup) | A Laravel, WordPress, or plain PHP project needs PHP-FPM. |
| [Custom Domain Suffix](/guides/custom-domain-suffix) | You want hostnames under a suffix other than `.test`. |
| [Services](/guides/services) | You want to see or control every bundled sidecar (Process Compose, Caddy, dnsmasq, Mailpit, …) in one place. |
| [Integrations](/guides/integrations) | You want to curate your sidebar, launch a local editor/terminal, or connect an external tool (GitHub, Linear, Sentry, …). |
| [Environment Variables](/guides/environment-variables) | A project needs runtime variables or shared templates. |
| [Project Groups](/guides/project-groups) | Multiple projects should start, stop, or restart together. |
| [SSH Tunnels](/guides/ssh-tunnels) | You need to forward a remote database, VPS/cPanel host, cloud VM, bastion-only service, or ML cluster dashboard onto localhost. |
| [Local AI (Ollama)](/guides/local-ai) | You want local models running — for dictation, agents, or your own tools — without managing an Ollama server by hand. |
| [Speech-to-Text](/guides/speech-to-text) | You'd rather speak a task card, commit message, or prompt than type it — and get clean text, on-device. |
| [Text-to-Speech](/guides/text-to-speech) | You want to hear text spoken in a natural voice, synthesized on-device. |
| [Image Generation](/guides/image-generation) | You want to generate images from a prompt on your Mac — a diffusion model or Apple Image Playground. |
| [Dumps](/guides/dumps) | You want a universal `dump()`/`dd()` viewer instead of an in-page dump. |
| [CLI Usage](/guides/cli-usage) | You want terminal parity with the app. |
